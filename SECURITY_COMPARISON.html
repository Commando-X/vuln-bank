def mask_card_number(card_number):
    """""
    Mask a card number, keeping only the last four digits.

    Full PAN and CVV must never leave the server (PCI-DSS 3.4 / CWE-359).
    """""
    if not card_number:
        return None
    card_number = str(card_number)
    if len(card_number) <= 4:
        return '*' * len(card_number)
    return '*' * (len(card_number) - 4) + card_number[-4:]

Accepted residual risk

Not everything was fixed, and these items are deliberately left open. Each is a decision with a reason, not an oversight.

R-02 · CWE-922
JWT still in localStorage

Requires migrating the whole client to HttpOnly cookies. Architectural change, deferred rather than half-done.

R-03 · CWE-256
Passwords and PINs still plaintext

Comparisons are now constant-time, but real hashing needs a data migration plan for existing rows.

R-04 · CWE-209
AI agent error text to client

Exception payload from the DeepSeek integration is still serialised to the HTTP response.

R-05 · CWE-352
No CSRF protection

State-changing forms still lack anti-CSRF tokens.

R-06 · edge
Cloudflare dashboard unknown

R-07 · CWE-668
Origin lock-down needs host access

R-09 · CWE-307
No brute-force protection on login

Rate limiting exists elsewhere in the app but is not applied to the auth.py login route.

R-10 · CWE-209
GraphQL resolver exceptions propagate

Database exceptions raised inside the resolvers reach the /graphql endpoint unhandled.

R-11 · CWE-400
Rate-limit counters are per-process

They live in a process-local dict, so under gunicorn's 4 workers the effective limit is four times the configured value. Fixing this needs a shared store.
